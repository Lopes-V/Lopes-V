Sistema de monitoramento utilizando **ESP32**, sensores, protocolo **MQTT** e dashboard desenvolvido com **Node-RED**.

**Principais conceitos:** IoT, comunicação publish/subscribe, sensores, dashboards e integração entre hardware e software.

[Ver projeto](https://github.com/Lopes-V/IOT_sistema-simples)

---

### Network Security Study

Projeto criado para aprofundar conhecimentos em **redes de computadores e cibersegurança**, utilizando cenários práticos envolvendo Ethernet, ARP, TCP/IP, roteamento, diagnóstico e análise de tráfego.

**Principais conceitos:** redes, segurança, troubleshooting, análise de protocolos e arquitetura TCP/IP.

[Ver projeto](https://github.com/Lopes-V/network-security-study)
